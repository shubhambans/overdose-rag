# rubric_sources/ (contents are git-ignored; this README is the only committed file)

Source documents for the tone rubric, the RAG "communication" collection, and judge validation. They are not
redistributed: some are copyrighted (the AMA page), and the MITI manual is marked "Draft: Do not cite without
permission". Download them yourself to reproduce the study.

| File | What it is | Used for |
|---|---|---|
| `miti_4_2_1.pdf` (+ `miti_4_2_1.txt`, `miti_clean.txt` extracted text) | Moyers, Manuel & Ernst. *Motivational Interviewing Treatment Integrity Coding Manual 4.2.1.* UNM CASAA, 2015. https://casaa.unm.edu/assets/docs/miti4_2.pdf | Judge rubric only (**not** indexed for RAG) |
| `tip-35-pep19-02-01-003.pdf` | SAMHSA. *TIP 35: Enhancing Motivation for Change in Substance Use Disorder Treatment.* Updated 2019. PEP19-02-01-003 | RAG `communication` collection; rubric |
| `VA-DoD-SUD-CPG_Final_for-508_v3.pdf` | VA/DoD Clinical Practice Guideline for the Management of Substance Use Disorders | RAG `communication` collection |
| `How to talk to patients/Words Matter - Terms to Use and Avoid…(NIDA).pdf` | NIDA. *Words Matter: Terms to Use and Avoid When Talking About Addiction* | RAG; stigma lexicon |
| `How to talk to patients/Words Matter_ Preferred Language…(NIDA).pdf` | NIDA. *Words Matter: Preferred Language for Talking About Addiction* | RAG; stigma lexicon |
| `How to talk to patients/How to talk about substance use disorders with your patients _ AMA.pdf` | American Medical Association web article (saved page) | RAG |
| `How to talk to patients/3 steps for talking with patients about substance use disorder (1).pdf` | "3 steps for talking with patients about SUD" | RAG |
| `Conversations/AnnoMI-full.csv` | AnnoMI: expert-annotated MI counselling transcripts, labelled high/low MI quality (Wu et al. 2022/2023) | Judge validation only (**not** indexed) |
| *(missing)* SAMHSA *Harm Reduction Framework* (2023) | samhsa.gov/find-help/harm-reduction/framework | **Not yet obtained**: SAMHSA blocks scripted downloads, and the file saved earlier under this name was a 404 web page. Download it in a browser to add it. |
