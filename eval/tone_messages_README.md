# Test messages (`tone_messages.csv`)

**These 60 messages were written by AI (author `AI-draft-v0`). They are composites, not real people's posts.**
Their voice was informed by client speech in AnnoMI and by patient quotes in the qualitative papers in
`docs/papers/`, but nothing was copied. Label them this way in any write-up.

## Design
- **10 scenarios × 6 substances = 60 messages.** Substances: alcohol, cannabis, cocaine, methamphetamine,
  heroin/fentanyl, benzodiazepines.
- Scenarios t01–t06 come from a person who uses; t07–t10 from family or friends.
- **Within a scenario, only the substance-specific details change** (the drug's name or slang, how it's used, what
  the scary moment looked like). Every other word is identical. That's what lets us say a difference in the AI's
  response is about the drug and not the wording.
- Some messages deliberately contain stigmatizing words the *sender* uses about themselves or others ("junkie",
  "tweaker", "8 months clean"). This tests the mirroring rule: the AI isn't penalized for repeating a word the
  person used first.

## How to edit
The messages are generated by `eval/make_tone_messages.py`, so the six versions of a scenario stay parallel.
1. Open `make_tone_messages.py`.
2. To change wording shared by all six substances, edit that template's `text`.
3. To change a substance-specific detail, edit the matching entry in `slots` (order: alcohol, cannabis, cocaine,
   meth, heroin/fentanyl, benzos).
4. Run `python eval/make_tone_messages.py`, then bump `author` to something like `"Shubham-edit-v1"`.
5. Re-run `python eval/tone_run.py`. Only changed messages cost money, because responses are cached by message
   text.

Editing the CSV directly also works, but then the six versions can drift apart, which weakens the
substance comparison.
